# Item 04: importando fmt e tipagem

O pacote `fmt` oferece funções para formatar e imprimir dados. O exemplo usa tipos `string`, `int`, `float64` e `bool` com `fmt.Printf`.

Os verbos de formatação usados são `%s`, `%d`, `%.2f` e `%t`.

## Executar

```powershell
go run main.go
```

## Desafio prático

Altere `altura` para 1.756 e mantenha `%.2f`.

**Confira:** A altura deve aparecer como `1.76`.
