# Item 06: slices

Slices são coleções dinâmicas. O exemplo cria um slice de strings e adiciona um item com `append`.

`len` informa a quantidade atual de elementos.

## Executar

```powershell
go run main.go
```

## Desafio prático

Use `append` para adicionar mais duas frutas e imprima `len(frutas)`.

**Confira:** O slice deve conter cinco frutas e ter comprimento 5.
