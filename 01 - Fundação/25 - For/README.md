# Item 25: for

Go usa `for` como sua única estrutura de repetição. O exemplo soma os números de 1 a 5 usando inicialização, condição e incremento.

Também é possível usar `for` como um `while` ou percorrer coleções com `range`.

## Executar

```powershell
go run main.go
```

## Desafio prático

Altere o limite do laço para somar de 1 a 10.

**Confira:** a saída deve ser `Soma: 55`.
