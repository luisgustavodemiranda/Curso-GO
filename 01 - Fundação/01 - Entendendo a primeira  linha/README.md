# Item 01: entendendo a primeira linha

Este exemplo mostra a estrutura mínima de um programa Go.

- `package main` define um programa executável.
- `func main()` é o ponto de entrada.
- `println` escreve uma mensagem no terminal.

## Executar

```powershell
go run main.go
```

## Desafio prático

Troque a mensagem por uma apresentação com seu nome.

**Confira:** O terminal deve mostrar exatamente o texto que você colocou entre aspas.
