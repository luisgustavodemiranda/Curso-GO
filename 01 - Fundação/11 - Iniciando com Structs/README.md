# Item 11: iniciando com structs

Uma `struct` agrupa campos relacionados em um novo tipo. O exemplo define `Pessoa` com nome e idade.

Os campos podem ser acessados com a notação `pessoa.Nome`.

## Executar

```powershell
go run main.go
```

## Desafio prático

Crie uma segunda pessoa chamada Ana, de 25 anos, e imprima seus dados.

**Confira:** A nova linha deve ser `Ana tem 25 anos.`.
