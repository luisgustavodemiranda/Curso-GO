# Item 08: funções

Funções agrupam uma tarefa em um bloco reutilizável. A função `somar` recebe dois inteiros e retorna o resultado.

A assinatura informa os tipos dos parâmetros e do retorno.

## Executar

```powershell
go run main.go
```

## Desafio prático

Chame `somar` com -4 e 6.

**Confira:** O resultado deve ser 2.
