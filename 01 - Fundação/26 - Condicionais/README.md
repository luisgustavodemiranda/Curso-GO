# Item 26: condicionais

A estrutura `if` executa um bloco quando uma condição é verdadeira. `else` trata o caminho alternativo.

Go não exige parênteses na condição e permite declarar uma variável antes dela.

## Executar

```powershell
go run main.go
```

## Desafio prático

Execute o programa com notas 6, 7 e 8, uma de cada vez.

**Confira:** a nota 6 deve mostrar `Em recuperacao`; 7 e 8 devem mostrar `Aprovado`.
