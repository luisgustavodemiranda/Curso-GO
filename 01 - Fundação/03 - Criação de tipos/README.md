# Item 03: criação de tipos

Go permite criar tipos próprios com `type`. O exemplo define uma `struct` chamada `Usuario` e um tipo numérico chamado `ID`.

Tipos próprios ajudam a dar significado aos dados e tornam o código mais claro.

## Executar

```powershell
go run main.go
```

## Desafio prático

Crie outro `Usuario` chamado Bruno, com `Ativo: false`, e imprima seus campos.

**Confira:** A nova linha deve mostrar `Bruno false`.
