# Item 23: pacotes e módulos, parte 3

Pacotes da biblioteca padrão, como `path/filepath`, fornecem soluções reutilizáveis para tarefas comuns.

O módulo deve importar apenas os pacotes realmente usados. O comando `go mod tidy` ajuda a organizar as dependências.

## Executar

```powershell
go run main.go
```
