# Item 13: métodos em structs

Um método é uma função associada a um tipo. O método `Area` recebe um `Retangulo` e calcula sua área.

O receptor aparece antes do nome do método: `func (r Retangulo) Area()`.

## Executar

```powershell
go run main.go
```

## Desafio prático

Crie um retângulo com largura 2.5 e altura 4.

**Confira:** O método `Area` deve retornar 10.
