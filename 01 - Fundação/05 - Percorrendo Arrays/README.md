# Item 05: percorrendo arrays

Um array possui tamanho fixo. O exemplo cria quatro notas e percorre todas usando `for` com `range`.

O `range` fornece o índice e o valor de cada posição.

## Executar

```powershell
go run main.go
```

## Desafio prático

Dentro do laço, imprima também o índice original fornecido pelo `range`.

**Confira:** Os índices originais vão de 0 a 3; os números das notas continuam de 1 a 4.
