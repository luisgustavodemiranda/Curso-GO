# Aula 14: Templates com arquivo externo

## Objetivo

Carregar templates com ParseFiles.

## Como funciona

`ParseFiles` carrega `templates/mensagem.tmpl`. O arquivo de template acompanha o exemplo. Execute dentro da pasta da aula, pois o caminho é relativo.

## Executar

Dentro da pasta desta aula:

```powershell
go run main.go
```

## Resultado esperado

```text
Ola, Ana!
```

## Desafio prático

Troque a mensagem no arquivo .tmpl e execute novamente sem editar main.go.
